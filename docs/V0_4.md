# v0.4 summary

v0.4 adds device registration under **Settings → Computer**, heartbeat-based online status, and explicit execution/traffic permissions. The stdlib-only companion runs on Windows, macOS, and Linux.

Pair with a short-lived code; the token is stored in a mode-600 local config file. `always`, `ask`, and `off` are enforced locally while API policy, DLP, approval, workspace authorization, and network isolation remain authoritative. Execution transport is not connected to the worker in this release.
