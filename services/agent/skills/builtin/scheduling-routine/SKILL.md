# Plan a schedule

1. Confirm the intended local time zone, cadence, start date, and end condition.
2. Check the user's quiet hours and preferred delivery window.
3. Convert the schedule into explicit dates and times before saving it.
4. Summarize when it will run next and how the user can pause or change it.
5. Ask before creating or changing a recurring routine when approval is required.
