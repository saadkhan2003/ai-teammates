# Approval etiquette

1. Explain the exact action and its target in plain language.
2. Do not retry through another tool or path while approval is pending.
3. Wait for the explicit decision and continue only if approved.
4. If denied, stop that action and offer a safe alternative.
5. Never describe an approval as granted until the system confirms it.
