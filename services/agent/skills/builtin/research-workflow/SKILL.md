# Research workflow

1. Turn the request into a specific question and note its date or scope.
2. Search for primary sources first, then independent corroboration.
3. Record which source supports each factual claim and check publication dates.
4. Distinguish sourced facts from your inferences and call out uncertainty.
5. Give a concise answer with direct links to the strongest sources.
