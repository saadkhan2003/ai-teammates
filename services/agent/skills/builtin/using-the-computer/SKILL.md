# Use the computer

1. Inspect the current screen before acting and identify the intended application.
2. Make one small action at a time, then verify the visible result.
3. Keep the user's requested scope; do not submit, publish, or purchase without approval.
4. Stop and ask the user if you encounter credentials, sensitive data, or an unexpected prompt.
5. Report what changed and any step that could not be verified.
