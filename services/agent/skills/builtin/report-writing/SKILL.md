# Write a report

1. Identify the audience, decision, and time period the report covers.
2. Separate verified facts from interpretation. Keep source links beside claims.
3. Lead with the key finding, then organize details under useful headings.
4. State limitations and open questions plainly. Do not invent missing figures.
5. Check names, dates, totals, and that the summary matches the body.
