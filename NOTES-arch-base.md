# arch/base: §14 row 1, generated port contract
contracts/box-contract.json is the single source; `node scripts/gen-box-contract.mjs` emits apps/api/BoxContract.g.cs, services/computer/src/box_contract.py, services/computer/scripts/box-contract.sh, apps/web/lib/box-contract.ts (each with an @generated sha256 header). `make contract-check` regenerates to a temp dir, diffs, runs the literal-port grep gate (scripts/check-no-port-literals.mjs, legacy allowlist in scripts/port-literal-allowlist.txt) and the unit tests (node, pytest, dotnet BoxContractTests). port(display N) = 5900/14000/13600/9222/9400 + N for N=1..8.
